## 保留的改动

三档共同使用共享植物材质、实例颜色和简单静态溪流，停止平面反射、Crest 模拟和高成本雾粒子/光束。主相机深度和树干碰撞数据保持，信息卡继续使用深度遮挡。最终 3D 与 UI 均使用原生分辨率；诊断缩放仅作用于 3D，UI、窗口和鼠标坐标保持输出分辨率。

|预算|低|中|高|
|---|---:|---:|---:|
|正常运行内部比例|100%|100%|100%|
|1757 株安全软植被池保留|879|1230|1582|
|阴影距离|关闭|30 m|60 m|
|阴影级联|关闭|单级|2|
|接触弯折|关闭|8 m|15 m|
|LOD bias|0.5|0.75|1.0|

软植被是确定、嵌套的整株筛选，未移除有碰撞的树木。上表仅代表清单内安全软植被，不包括全部植被。Terrain 草层保留原有三档密度/距离规则，独立记录地图单位与密度，地图单位不等于可见草实例数。没有新增加浓雾作为隐藏预算。

CPU 诊断发现溪流附近恐龙预测碰撞查询产生较大尖峰，因此增加保守的岩石粗筛、身体半径缓存和每帧地形树缓存；精确窄阶段、核心计时和恐龙更新频率保留。现有恐龙尺寸改动未覆盖。20,000 组随机几何查询与原算法对照通过。

## 未保留的实验

显式空间块 `DrawMeshInstanced` 实验在深度对照中出现 30,883 / 2,073,600 像素（1.489%）差异；原生重复绘制对照为 0。因不满足信息卡/水面深度要求，实验已从产品代码移除。相关短测不能作为最终优化收益。记录和实验源代码留在 `Logs/RuntimePerformance/RejectedInstancing/`。原生 Renderer 的共享材质与 GPU instancing 仍保留。

脚部/相关动画工作在诊断中约为 0.1～0.2 ms，未证明是瓶颈，故未引入远处恐龙动画降频调度。

## 正式测量

标签前缀 `alltiers-formal-20261112`。顺序运行可见 1920×1080 非 Development Player；四种场景各预热 15 秒、采样 60 秒、重复三次。每档先测保留对照包，再测优化后原生 1080p；低、中另测分档内部比例，高档原生即最终。采样中最小化、锁屏或中断即作废。

完整数据：[AllTierComparison.md](AllTierComparison.md) 和同名 JSON。均值 FPS 包括长帧；帧时间中位数使用三次中位数的中位数，P95/P99 报告最差一次。不作未经测量的 60 FPS 承诺。

以上是包含长帧的实际平均 FPS，不是中位帧时间的倒数，所有前后数据均为原生 1920×1080。最终配置最差场景 P95：低 47.43 ms、中 74.91 ms、高 50.84 ms；P99 仍有 49～117 ms 的长帧，不能宣称稳定 60 FPS。三档四场景的平均 FPS 均明显提高，未发现相对于优化前的持续退步。

75%/85% 内部比例已经完成同等正式测试，但未选为默认。低档 75% 相比优化后原生：溪流 69.5→89.5、漫游 119.2→149.3 FPS，但森林 114.4→105.9、近景 75.2→64.6 FPS，且近景 P95 47.43→73.85 ms。中档 85%：森林基本持平、溪流约 +6%，近景约 -7%、漫游约 -13%。收益混合且部分场景退步，因此保留原生清晰度，不默认使用缩放合成路径。`-jwRenderScale` 仅作为可重复诊断选项保留，不能将某个缩放场景的收益归于合批。

中档优化前第一组在 11:42 因锁屏中断，已标 INVALID 并归档为 `alltiers-formal-20261112-before-Medium-interrupted-1142`，未混入结果。用户解锁后重跑完整中档；新增采样期间唤醒请求，结束后恢复。全部纳入报告的组均有完成标记、有效画面、1080p 输出、15/60/3 时长、固定机位、六只恐龙和 775 个硬树阻挡匹配，近景恐龙提交覆盖率满足校验。

## 最终诊断与剩余瓶颈

同源码 Development 包另做三档 3/10/1 短测，详细计数：[AllTierDiagnostic.md](AllTierDiagnostic.md)。这些短测只用于归因，不替代正式 Release 数据，也不能把各计数器相加；计数器与帧时钟可能错一帧。

- 渲染提交仍较重：诊断各场景绘制计数中位数约 2387～8444；CPU 渲染线程中位数约 2.6～7.9 ms，GPU 约 2.7～8.8 ms。原生实例批次非零，但大量几何与深度/阴影提交仍未合为少量批次。
- 恐龙普通漫游路径仍有 CPU 尖峰。总 AI 中位数仅约 0.35～0.74 ms，但 P95 约 8.6～24.3 ms；高档溪流最大约 87.6 ms。分项显示主要集中于 Roaming，不能因中位数小就宣称 AI 尖峰完全消除。后续应进一步细分漫游预测/寻路查询；本轮保留核心更新正确性，未直接跳过 Agent.Update。
- 脚部中位数多数约 0.08～0.10 ms，高档近景约 0.43 ms；植物交互中位数约 0～0.72 ms，均不是优先大幅降频的依据。
- Development GC 分配中位数约 1.9～4.2 KB/帧，尚有少量分配。正式 Release 的 GC 与部分脚本计数器不可用，原始报告明确标注 unavailable，未以零冒充，也未证明每个长帧均由 GC 导致。

最终 Runtime/Editor 编译均 CSC EXIT 0，报告校验器 11 项通过，Release/Development 构建均退出 0。最终 Release smoke 正常退出并通过；吼叫/跟随、返回等待和 30/60/144 FPS 模拟动作/足部时序通过。测试输出单独归档至 `Logs/RuntimePerformance/alltier-final-*`，历史动画报告已还原，未覆盖原始素材。五个已有尺寸修改文件与测量前 SHA-256 一致。

本轮交付保留上述性能提升与已知限制。交通脱困/目标恢复的三个旧失败和物理脑控设备验收仍未解决；没有承诺所有场景稳定 60 FPS。
