# 全场景树高与重叠处理

## 操作入口

先停止 Play 并保存场景，然后使用 Unity 菜单 `Jurassic World > Environment > Tree Heights`：

- `Apply and Verify`：保存实施前 Main 副本，撤下已授权的近乎重合树，再应用全场景树高。验证位置、朝向、树种、地形及恐龙尺寸不变，重复应用、撤销及尺寸重放一致。
- `Undo Height Adjustment`：恢复本轮记录的原始尺寸。后续单独修改过尺寸的树会跳过，避免覆盖其他编辑；重叠树撤下独立保留。
- `Restore Withdrawn Overlap Trees`：重新启用撤下的场景树，或恢复地形树实例；关闭自动重叠撤下。已启用的高度规则仍然生效。

统一配置为 `Assets/Editor/TreeHeightPolicy.json`，原始及应用后尺寸记录为 `Assets/Editor/TreeHeightLedger.json`。两者在成功应用时生成。重叠恢复记录独立保存在 `Assets/Editor/TreeOverlapWithdrawals.json`。

中心为 X[-60,60]、Z[-50,82]，主体5–8米、上限10米；外围主体8–12米、上限14米；中心外10米平滑过渡。原本矮小的树不会被拔高。所有缩放均为等比例，不改共享植物资源。

## 重叠处理范围

只读初始审计找到7对根部平面距离不足5厘米的树。用户已明确选择“保留位置，撤下每对中一棵并保留恢复记录”，因此这7棵是原计划保持棵数要求的例外。普通树冠交叠保留；避障代理圆交叠不能直接当作木质网格相交。

原场景树在原父对象下停用，保留变换；地形树保存原始位置、朝向、原型、宽高缩放及颜色字段。重建时按记录撤下重复实例。完整场景 Bake 通过现有枝叶准备入口依次应用重叠规则和高度规则。

## 报告含义

- `Audit.md`、`OverlapPairs.csv`：应用前独立统计，排除枝叶系统生成的地形树代理。
- `OverlapCleanup.md`：实际撤下数量及恢复来源。
- `HeightReport.md`、`Trees.csv`：通过高度验证后生成的分区与逐树高度统计、树冠覆盖估算。
- `before-0..3.png`、`after-0..3.png`：固定入口、林内、侧面、俯视机位。
- `Failure.md`：若净空或一致性检查失败，记录停止原因；该次树高尺寸回滚，授权的重叠撤下独立保留。
- `Checkpoint/Main_AtApplication.unity`：实际应用前最新 Main；较早的 `Checkpoint/Main.unity` 是任务开始时快照，不应用它覆盖其他并行场景修改。

树高静态检查只禁止新增保护区域/路线的硬木冲突，不会把既有冲突标记为已修复。先前普通漫游的支撑脚漂移和扩展区外碰撞仍需各自的运行验收结果证明修复。代码编译通过不等于场景应用或运动验收通过。
