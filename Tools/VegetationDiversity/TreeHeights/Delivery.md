## 树高为什么没有提交

样板中的 `Assets/NatureStarterKit2/Nature/tree01.prefab` 位于 **X=-17.64、Z=31.08**，原高 **11.360m**。等比例缩小、根部贴地后，在允许的 **5–10m** 内未找到不新增路线硬木净空冲突的尺寸。

独立复核按5m到10m等距采样61个高度（步长约0.0833m），每个候选新增3–9个路线高度层扫掠冲突；10m候选仍新增3个。逐候选记录见 [BlockedHeightConflicts.csv](BlockedHeightConflicts.csv)，ID低于1000000表示路线扫掠，高于或等于1000000表示预留身体姿态。当前失败记录均为路线扫掠。

按照已批准方案“无解时停止并恢复该批”，**整批树高已回滚，高度规则配置保持禁用**。没有移动树木、放宽运行碰撞规则、削改树种资源，或把失败标记为通过。已授权的7棵重叠撤下独立保留。失败堆栈见 [Failure.md](Failure.md)。

因此中心/外围主体树高80%占比、10m/14m上限及全场景树高视觉验收**本轮未达成**。保存后各归属高度中位值/最高值仍分别为：地形10.024/15.772m、原场景8.928/20.437m、样板6.706/11.360m、扩展6.620/11.298m。完整前后统计见 [Before-Audit.md](Before-Audit.md)、[After-Audit.md](After-Audit.md)。

## 入口与验证

Unity 菜单 `Jurassic World > Environment > Tree Heights`：

- `Apply and Verify`：统一高度应用及净空、一致性验证；当前场景仍会因上述树停止。
- `Undo Height Adjustment`：仅恢复匹配记录的树尺寸，保留其他场景编辑。
- `Restore Withdrawn Overlap Trees`：恢复这7棵并停用自动重叠撤下，已启用的树高规则仍独立生效。

生成器、分区重建和完整 Bake 共用枝叶准备前的高度/重叠后处理。原中心18–19.4m树冠特例已移除；本轮未重做整场景 Bake，不将入口接入视为完整 Bake 验收通过。高度规则未启用时不自动缩小其他树。

Runtime 与 Editor C# 编译均通过。应用、失败回滚、硬树干/硬枝数据重建、导航及枝叶重新准备已执行；重叠恢复和重放一致性检查通过。树高流程在首个无解树处停止，未进行未达成树高状态的30/60/144 FPS长时运动与路线、互动回归，不将过去结果当作本次通过。先前脚漂与扩展区外碰撞失败继续保留，未声称修复。
