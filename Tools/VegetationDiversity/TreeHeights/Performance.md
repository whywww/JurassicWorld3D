# 固定机位渲染计时

`before-timings.csv` 与 `after-overlap-timings.csv` 使用相同1280×720机位，各预热8次、采样30次 Camera.Render CPU耗时。后者是撤下7棵且树高回滚后的状态，不是成功降高后的性能。

|机位|实施前CPU Render中位ms|撤下后CPU Render中位ms|
|---|---:|---:|
|入口|17.1461|14.7085|
|林内|34.5078|14.8833|
|侧面|31.6993|17.1683|
|俯视|17.8579|12.2524|

GPU所有机位有效样本数均为0，**不可用**。UnityStats绘制调用计数在此批处理模式全部返回0，视为**计数不可用**，不解释为场景无需绘制。CSV保留原始返回值。

这是编辑态静态画面对照，包含CPU渲染提交及可能的同步等待；缓存、编译和批处理进程差异可能影响数值。它不等同于启用所有恐龙、枝叶交互和导航后的整帧CPU耗时，不能据此推断动态帧耗改善或判定15%性能目标通过。
