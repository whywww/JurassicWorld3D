# 中心加密 Play 渲染开销

实际 Unity Play Mode；三个相同路线视点；1280×720 RenderTexture；每个视点预热20帧，测量60帧。

| 路线视点 | 修改前 Camera.Render CPU 中位 ms | 第一阶段 CPU 中位 ms | 差值 ms |
|---|---:|---:|---:|
| 0 | 7.58 | 10.79 | 3.21 |
| 2 | 6.31 | 13.23 | 6.92 |
| 5 | 5.05 | 10.96 | 5.91 |

合并样本 CPU 中位：6.14 → 11.28 ms（+83.6%）。

Editor Play 帧间隔中位：17.12 → 31.72 ms。含编辑器调度、额外测量渲染和同步等待，不能作为发布版 FPS。

本次环境没有提供有效 GPU 帧计时；Camera.Render 数值是 CPU 渲染提交与等待耗时，不等同于 GPU 时间。

修改前基线关闭加密根对象，并临时恢复五棵预览树、被区域替换的场景树及完整地形树数组。基线地形使用内存副本；测试只改变 Play 内存状态，不修改场景或地形资产；无截图。恐龙路线运动另用 RunWithoutImages 验收。
