合并样本 CPU 中位：7.64 → 13.13 ms（+72.0%）。

Editor Play 帧间隔中位：20.20 → 34.86 ms。含编辑器调度、额外测量渲染和同步等待，不能作为发布版 FPS。

本次环境没有提供有效 GPU 帧计时；Camera.Render 数值是 CPU 渲染提交与等待耗时，不等同于 GPU 时间。
