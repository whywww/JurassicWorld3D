# 交互动画时序修复 — 2026-10-20

已移除 `NaturalMotionTime` 对整段表演和转身的减速。交互动作按片段正常时间推进，转身保留原有 `turnPlaybackSpeed`；脚锁只限制实际修正量，不预扣预算拖慢动画。受阻恢复检查采用相同的下一帧采样，不再依赖旧限速。

完整动作预检、混合包络、运行时身体扫掠、同伴检查及安全结束／等待出口流程保留。空间不足时等待、换位置或结束，不以慢放完成动作。

路线转身的脚锁修正同时检查剩余轨迹，防止一次局部安全的修正把后续动作推到通道外；无法安全修正时保留原有根轨迹，由脚部 IK 继续求解，不拖慢动画或穿越边界。

## 根位移连续性

旧转身将朝向变化集中到少数接触采样，且落脚时会复用过期支撑锚点。修复为相邻脚步采样连续累加，并将旧 90° 转身的朝向过渡分散到约 0.2 秒窗口。

|动作|旧最大相邻根位移米|最终最大相邻根位移米|
|---|---:|---:|
|turn 90 left|1.5467|0.1714|
|turn 90 right|0.2923|0.1284|
|mama cave bite out|1.4497|0.0914|

这些是约 60 Hz 的**动画采样间隔**，并非游戏每帧的位移；转身执行时还应用原有 0.2 倍率。采样修复仅更新共享动作配置中的 `rootOffset` 和旧转身 `yaw`，保留净转角、接触信息、原始动画片段及播放倍率。烘焙工具也使用连续重建，避免下次烘焙重新引入跳变。
