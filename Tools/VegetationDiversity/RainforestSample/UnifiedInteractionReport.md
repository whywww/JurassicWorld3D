# 霸王龙统一互动范围交付

日期：2026-10-20。

## 生效规则

| 条件 | 行为 |
|---|---|
| 水平距离≤32米，夹角≤20°，连续可见0.3秒 | 正面Intro |
| 水平距离≤32米，20°<夹角≤50°，连续可见0.3秒 | 对应左右Intro |
| Intro完成，玩家可见，路径和动作安全 | Follow；玩家已在10米内则Near |
| Follow期间距离≤32米、夹角≤50°、无遮挡 | 持续Follow |
| 玩家可见且距离≤10米 | Near |
| Near中玩家可见、距离>15米，路径和动作安全 | 恢复Follow |
| 超距、超角或硬障碍遮挡连续3秒 | 请求安全结束，按当前动作及支撑脚状态衔接 |

角度参照恐龙当前朝向，距离参照恐龙根节点与玩家的水平位置。±20°只决定发现动画；从侧面转到正面不会使Follow失效。不再扩大为48米或±90°。

## 实现

- 统一可见判定与失效原因，保留其他恐龙不使用霸王龙动作流程时的原有逻辑。
- Intro、Follow、Near、侧面追随及这些阶段的空间等待共用每帧一次的丢失计时。重新可见清零；切换Follow不清零。返回阶段不重新触发互动。
- 不可见玩家不更新追随目标、不触发Near或恢复Follow。Intro完成时若只是短暂丢失，则保持最后安全姿态等候；超时后安全结束。
- Follow目标设在Near阈值内0.25米，容纳导航投影与8厘米到达容差。可见玩家仍在Near外而路径已经结束时，进入原有导航空间等待；不可见时等候丢失容错，不根据隐藏玩家位置切换阶段。
- 保留Near的10／15米回差、原有30秒累计跟随上限、冷却、动画时序和脚锁；特殊表演只检查同类身体，行走步骤继续检查树木、实体、边界、NavMesh和同类。
- HUD显示可见状态、丢失计时与结束原因；Blocked直接显示已记录的障碍原因。失视与超时使用各自的直白结束原因，不再使用空间失败标记。

## 回归结果

- Unity运行时及编辑器脚本编译通过，现有警告未扩大处理。
- `Jurassic World/Acceptance/Verify Unified TRex Visibility`通过：32米、±20°、±50°边界，互动前后范围一致，Near回差，不可见玩家不触发Near，登记树干和岩石遮挡，未登记草蕨碰撞体不遮挡。
- 可见计时按30／60／144 FPS模拟，覆盖Intro／Follow／Near与空间等待共18组：短暂丢失后恢复、隐藏目标不更新、连续3秒后请求结束（离散误差≤1帧），结束原因保留失视文本。
- 现有24个Play运动场景全部通过，覆盖正面和左右互动、静态穿模表演、掉头及沿历史回程、同伴进入空间；检查行走碰撞、同类身体不穿透、瞬移、持续原地踏步及支撑脚误差。详细数值见 `Acceptance.md`。
- 六条路线在现有路线组合中全部通过连续运动和同伴净空验收；日志：`Logs/unified-routes.log`。
- 霸王龙与伶盗龙Main避让、耦合返回恢复漫游通过；日志：`Logs/unified-safety.log`、`Logs/dinosaur-main-encounter-result.txt`。
- 最终判定、运动、避让批处理退出码均为0。路线测试在最后的Follow到达容差修正前完成；该修正仅作用于互动目标，不修改路线流程。

## 范围与限制

判定细项见 `UnifiedVisibility.md`。计时单测调用生产可见更新函数；运动安全由独立Play回归验证，模拟FPS不代表实机渲染性能。本轮未保存场景或改动植被、导航资产、动画资源和动作包络。此前宽动作包络引起的空间误判已由“表演只查同类、行走继续查静态”的拆分消除。
