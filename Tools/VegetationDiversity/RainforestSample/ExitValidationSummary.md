# Follow 出口与 Step4 验收汇总

2026-10-20，Unity 2022.3.62f3c1。Main 实际互动配置：`SideInteractionProfile.asset`，26 个动作。

## 已完成

- Follow 保留完整验证的出口，沿实际跟随路线前看 8 米、每 2 米取样。后方树木只影响实际碰撞的候选，不能原地掉头不再直接结束 Follow。
- Step4 从 Ending 的实际位置和姿态重新接入出口，优先直行／小转向，接入验证过的漫游路径后才退出互动状态。
- 0.5 秒复核；偏离 1 米／朝向变化 15°提前复核；无解安全待机后每 2 秒重试。每帧最多 2 个出口路径查询、32 个姿态检查，0.5 毫秒软预算。
- F4 分开显示当前阻塞、出口搜索／等待、预测失败和历史失败；Scene 选中霸王龙显示青色路径及黄色连接点。

## 计算开销

相同固定姿态、相同空地导航与身体包络：预热 5 秒，采样 10 模拟秒（60 FPS）。新旧参考代码均在同一夹具中测量；旧参考通过反射调用，包含反射开销。仅比较算法服务耗时。

|指标|旧完整转身复核|新出口维护|
|---|---:|---:|
|每模拟秒 CPU 工作（毫秒）|16.6005|0.6327|
|服务时间中位值（毫秒）|7.7456|0.3120|
|P95（毫秒）|8.6410|0.3532|
|最大值（毫秒）|9.0725|0.3587|

固定姿态新规划总路径查询 1 次、完整搜索 1 次、复核 30 次（含预热）；最长查询 0.0086 毫秒。初始搜索中最长不可拆分姿态检查 2.4499 毫秒、超软预算 3 次。实际场景搜索服务切片偶有更大峰值，逐项见 ExitPlannerAcceptance.md；软预算不是硬实时上限。

线程 GC 分配 API 未通过显式分配探针，标记不可用。整个夹具帧分配中位值／P95／最大值为 3892／13788／178064 字节，包含编辑器、旧参考与场景开销，不能归因于新规划器。没有将零读数当作零分配，也没有推断整帧 CPU 或 GPU 性能。
