# 中心密林补空

Unity入口：`Jurassic World > Environment > Center Gap Fill`。

- `Build and Verify`：按西南、东南、西北、东北顺序构建与验证。
- `Rebuild/<分区>`：按记录恢复指定分区，不重新抽取种子或扩大保护范围。
- `Undo/<分区>`、`Undo All`：仅撤销本轮归属对象，保留原植被与恐龙修改。

配置：`Assets/Editor/CenterForestGapFill.json`。以GUID记录植物来源，包含冻结的1m互斥保护网格、6条实施前可达路径及分区植物绝对变换。重新构建不累计数量。恢复后仍需验证当前硬木及身体净空；环境改变导致不安全时停止该批。

本轮范围X[-60,60]、Z[-50,82]。四区以X=0、Z=16分界，固定种子732101～732104。10m局部网格以冻结参考密度0.076171875棵/m²的65%计算目标，原过密格不追加，也不抵消其他格缺口。所有原植物保持位置、尺寸和树种，关闭的统一树高不重启，先前撤下的7棵树不恢复。

新增乔木5～8m为主、上限10m，尺寸等比例缩放。完整硬木检查沿用现有木材分类与高度分层：路线/动画身体、互动林隙、出生出口及连接路径不能侵占；既有与新增木质部分不能相交。树冠叶片可交叠。蕨类0.3～0.8m、软叶灌木0.5～1.1m分簇填充；含硬木材质的灌木不转换成可穿行地被。柔性地被通过独立标记接入既有叶片交互，不冒充树干。

输出：`Layout.md`、`Plots.csv`、`Protection.md`、四机位`before/after-0..3.png`，运动与动态性能报告由验收入口分别生成。构建通过不能代替运动/性能通过。历史脚漂与碰撞问题继续保留，不声称本轮修复。

完整场景Bake在原植被生成后调用本轮GUID重放；撤销不会修改旧样板或扩展区种植记录。实施前副本位于`Checkpoint/`，避免用整场景副本覆盖其他任务后续编辑，日常撤销使用上述独立入口。
