# 恐龙枝叶交互

Main.unity 已启用身体、头颈和尾巴的骨骼胶囊扫掠。接触附近的树叶和细枝会被拨开；接触主干时也会将受力传到柔性树冠，离开后弹性回弹。树干和连接处固定。恐龙移动、避树及脚锁逻辑保持原有行为。

## 使用

- 直接打开 Main.unity 进入 Play Mode。
- 在场景根节点 `Dinosaur Foliage Interaction` 的 `FoliageInteractionSystem` 调整叶片位移、细枝位移、频率和阻尼；默认分别为 0.45 米、0.20 米、2 Hz 和 0.35。运行时位移上限为 0.45 米，以匹配渲染包围盒。
- 临时关闭该组件的 `Interactions Enabled` 会清空接触、回弹和历史位置。树木恢复原网格、材质和包围盒。
- 编辑态菜单 `Jurassic World > Environment > Foliage Interaction > Restore Original Trees` 关闭并恢复原始树实例、材质、附加顶点数据和静态标记。
- 重新启用使用同一菜单下的 `Prepare and Enable`。配置文件存在时，全场景 Bake 会在植被布局完成后自动准备交互；准备前会先恢复上次的转换。
- 修改植被布局前先恢复交互。恢复时检查剩余 Terrain 树与原型签名，防止覆盖准备之后新增或修改的树。

## 实现

恐龙胶囊在编辑态根据蒙皮骨骼和顶点拟合，运行时在脚锁之后读取动画姿势。出生、瞬移和重新启用不产生跨地图扫掠。

交互树采用共享的附加顶点数据记录柔性权重，保留第三方模型、原始顶点法线和颜色。每棵树按需创建三维位移场，节点默认间距 1.5 米、每轴最多 16 个。空间索引只查询附近树；仅受力或回弹时切换交互材质，静止时恢复原绘制路径。各 LOD 和阴影使用同一位移场。交互材质关闭 GPU 实例化，因为 Unity 2022.3 不支持实例化与附加顶点数据同时使用。

当前布局接入 380 棵近路独立树。现有 1659 棵 Terrain 树没有进入可接触范围，所以没有迁移；转换能力通过临时放在路线旁的 Terrain 树验证。地面蕨类、灌木、折断、落叶和枯枝刚体未接入。

## 验证

空间索引的世界包围盒使用局部 `Bounds` 累积八个角点、扩展变形范围后再赋值。直接对 `WorldBounds` 属性调用 `Encapsulate` / `Expand` 会因值类型副本丢失修改，让大树退化为一个角点并漏检；已增加旋转和非等比缩放下的回归检查。实际骨骼接触对照记录位于 `Logs/FoliageInteraction/ContactDiagnosis.txt`。

菜单 `Jurassic World > Acceptance > Foliage Interaction — Verify and Record` 检查扫掠中部与端点、高度错开、出生与瞬移、30/60/144 FPS 弹性稳定性、多接触限幅、两秒回弹、持续模拟零 GC、准备幂等、Terrain 树完整恢复及树干阻挡查询一致性，然后在实际 Play Mode 中比较关闭、静止、接触三种状态并输出录制帧。

`Verify Green Tree Rendering` 也覆盖 Nature Starter Kit 2 的 `tree01`～`tree04`，检查直接枝叶接触、主干接触引起的树冠画面变形和两秒恢复。运行态空间索引包含烘焙的主干截面，避免树冠较高时漏掉低处的身体接触。回归检查另验证身体与树冠完全分离时的主干受力传递，并拒绝远处接触。

验证日志、同机位图片、120 帧录制和动画预览位于 `Logs/FoliageInteraction`。性能测量与录制分开，计时覆盖 CPU 渲染提交及交互更新，不代表 GPU 或发布版完整帧率；完整帧耗的 5% / 10% 预算仍需在目标 Player 中用 Profiler 验证。
