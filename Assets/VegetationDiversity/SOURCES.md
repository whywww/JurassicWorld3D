The model archives provided by the project owner are retained under `Assets/ThirdParty/VegetationDiversity/Incoming`:

The five-tree comparison sources were downloaded from the official Poly Haven API with 1K textures. Each source folder contains `download-manifest.json` with the official URLs and verified MD5 hashes. Prepared model triangle counts and native dimensions are recorded in `Tools/VegetationDiversity/five-tree-model-report.json`. These five prefabs are not connected to Bake or full-layout seeding.
