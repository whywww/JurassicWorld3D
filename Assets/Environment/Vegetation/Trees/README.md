# Trees: Phase 2 Forest Layout

## Asset layout

Prepared tree prefabs are under `Prepared/Prefabs/`, with source packages kept in `Source/`. Prepared models, materials and prefabs are generated by the preparation menus; do not edit them by hand.

## Current central forest stage one

The five imported species have now been visually approved. **Central Forest Densification / Stage 1** uses them in natural groups across X[-60,60], Z[-50,82], alongside existing vegetation. The former comparison arrangement is retained inactive under **Preview Backup** for the Remove command. The following preview instructions describe the original comparison workflow; do not rebuild that separate preview while reviewing the forest.

Use **Jurassic World > Environment > Central Forest** to build Stage One, append Stage Two after review, validate, remove this planting, while Play render cost comparison is under **Jurassic World > Diagnostics > Central Forest**. Stage One is saved in Main; Stage Two is prepared but has not been executed. `Assets/Editor/CentralForestStage.json` stores the confirmed stage, and Bake rebuilds only that stage after the existing passes.

The current Stage One keeps **399 central trees**. Autumn forest occupies **20.02% of the full terrain footprint in the northwest**, with an 18m transition and sparse fringe. Of the 337 autumn trees originally inside the new region, **169 remain**; the rest are replaced with green trees at their existing sites. Regional conversion retains one tree for each of 313 Terrain instances and 16 original scene trees. Original instance fields and scene parents/transforms remain in `ForestRegionBackup` for Remove. Terrain heights, ground/creek layers and perimeter prototypes are unchanged.

Tree planting and movement use the same baked **torso/hips** animation envelope, in 0.5m height layers, with **zero additional safety margin**. Explicit skin-bone mappings cover the currently enabled ground dinosaurs; a new species requires a mapping before building. Head, tail, limbs, foliage and lateral branches do not enlarge the tree exclusion. Rocks/deadwood retain full-body +1m clearance. Runtime circles only select nearby trunks; oriented core-versus-stem sections decide blocking. Route candidates start at the safe stem edge and prioritize the first 0–2m. Spawn exclusions and dinosaur-to-dinosaur separation are retained.

All 18 observation segments now have trees on both sides within 12m. Median left/right stem distance falls from 8.15m to **3.4m**; 17/18 segments have estimated overhead crown projection. These are geometry estimates, not rendered leaf pixels. **373 non-solid grass/fern/small-shrub objects** occupy sparse irregular patches on all six routes, alongside 697 forest understory objects. No images were generated; inspect Editor Play for the visual result.

Density accounting preserves the approved 7084m² denominator and 399-tree total: **65.1%** of the original perimeter reference. The relaxed core clearance makes 10608m² available, where the same trees yield **43.5%**. These are different denominators, both explicitly reported. Reaching 65% with the new denominator would require 198 additional trees; this revision follows the approved instruction not to increase the central total.

Reports in `Tools/VegetationDiversity/CentralForest`: `DensityReport.md`, `NorthwestRegion.md`, `RouteEdges.md`, and `PlayPerformance.md`. `CentralForestStage.json` persists layout version 4, stage 1, seed and the 337-tree baseline, so repeat builds/Bake do not halve the count again. Remove restores the original pre-densification vegetation; Stage Two has not run.

## Original five-tree comparison workflow

The original **Poly Haven Five Tree Preview** showed one each of Island Tree 01, Island Tree 03, Tree Small 02, Jacaranda Tree, and Fir Tree 01 (variant A). Prefabs retain native model sizes; the original Jacaranda comparison instance used 65% scale and the other four used 100%. This comparison was approved before forest distribution and is now retained as an inactive backup.

The comparison build, validation and capture commands have been retired. Existing inactive preview backups remain as historical records. Prepare the approved species through **Jurassic World > Assets > Prepare Five Forest Tree Species**; use the Central Forest commands for production planting.

To reproduce the new assets, run `Download-FiveTreePreview.ps1`, then run `prepare_five_tree_preview.py` and `reduce_preview_foliage_lods.py` with Blender in background mode and the project directory after `--`. Run the two preparation scripts in that order; the first regenerates the intermediate report used by the second.

The base **Phase 2 Biome Vegetation** pass adds 30 vegetation groups, one banana grove, 60 trees and 180 fern/bush instances. Its original west-autumn/east-tropical arrangement is subsequently corrected by the northwest regional pass during Bake. The 12 banana trees remain in the southeast grove (x=50–70, z=-65 to -35). Use the Central Forest commands for the revised layout; a full Bake reapplies the region and confirmed stage after the base passes.

The scene includes the previously reviewed 15-group layout plus 15 added groups to fill more of the player exploration area.

The Sketchfab Banana Tree source is supplied as `Palm.fbx`. Its bark vertices are widened 1.7× in the prepared `BananaTree.fbx` so the trunk remains visible at the scene's 2.8–4.0 m scale. Leaves, UVs, and bark material remain from the source. Regenerate it with `prepare_models.py banana <source Palm.fbx> <prepared BananaTree.fbx>` if needed.

Production layout commands are under **Jurassic World > Environment > Vegetation**; asset preparation and diagnostics have their own groups:

- **Assets > Prepare Biome Vegetation** refreshes the Built-in RP materials and prefabs from the prepared FBX files.
- **Build Phase 2 Full Layout** replaces this scene root idempotently and re-registers scene-tree trunk avoidance.
- **Validate Phase 2 Full Layout** checks 30 groups plus the banana grove, 60 tree trunks, 12 clustered banana trees outside the creek, biome placement, all six route loops and turns, existing island saplings and central rocks, runtime obstacle registration, and Fab tree LODs.
- **Diagnostics > Vegetation > Measure Phase 2 Render Cost** compares offscreen 1280×720 CPU render submission with the root off and on, and reports mesh/texture memory. It does not measure GPU frame time.

`Jurassic World > Scene > Bake Scene` regenerates the full layout after terrain, rocks, and central islands are rebuilt. The bake hook does not add trees to TerrainData or alter ForestSeeder.

The scene uses the prepared Sketchfab Banana Tree prefab in the 12 former coconut-palm slots. A fixed seed distributes them among three overlapping southeast clusters with randomized 2.8–4.0 m heights and headings. Placement fails rather than spreading a tree outside the clearing or into the creek. The retired Sketchfab Palm Trees source archive, models, textures, materials and prefabs have been removed. The four palm instances in the pre-Phase-2 checkpoint have also been removed; the Banana Tree source named Palm.fbx is retained.

The previous coconut-palm layout measured 3.15 ms baseline vs 4.74 ms with the vegetation root active (+1.59 ms CPU render submission) at 1280×720. Re-run **Measure Phase 2 Render Cost** after this banana-tree replacement; GPU frame time is not measured in batch mode.

The earlier 30×30 m prototype layout and its validation/performance commands have been retired in favor of Phase 2. Its asset preparation entry point remains available.
